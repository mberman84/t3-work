# Use T3Work as your default browser

The installed desktop app can be your default web browser on Windows and macOS. Open
**Settings → Browser** and choose **Make default**. On Windows, select **T3Work → Set default**
in the settings window. On macOS, choose **T3Work** under **Default web browser**.

T3Work uses its own persistent browser by default, with cookies and logins saved between visits.
[Import logins](browser-import.md) from a supported browser to get started. Chrome live stays
available as an optional profile for individual tabs.

Links you open from other apps open in T3Work. When the thread on screen shows its browser panel, the link opens there as a new
tab. Otherwise it starts a new thread without a project, with the browser panel maximized on the
page, so you can ask an agent about it right away.

To switch back, choose another browser in your operating system’s default browser settings.

Pull request links for a connected project open in the pull request view when opening pull
request links in the app is enabled. Other links still open in the browser panel.

HTML files you open from Finder open the same way. [Prompt links](prompt-links.md) to
app.t3.codes open in the app as a draft.

A link that launches T3 Code waits until the app has connected to its environment, then opens.
